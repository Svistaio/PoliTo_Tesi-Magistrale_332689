
% Questa installazione di TeX Live non contiene il pacchetto «cm»: la mappa
% pdftex.map non associa i font CM a versioni scalabili e pdfTeX genererebbe
% bitmap (Type3), che microtype (espansione) rifiuta; lo stesso vale per i
% simboli AMS (msam/msbm, es. «\R» = \mathbb{R}). Le copie di «amsfonts» sono
% comunque presenti, quindi qui se ne integrano le mappe a livello locale
% (soluzione al problema d'installazione: «tlmgr install cm symbols» + «updmap-user»).
\ifdefined\pdfmapfile\pdfmapfile{+cm.map}\fi
\ifdefined\pdfmapfile\pdfmapfile{+symbols.map}\fi

% realtà condivisi perché «definizioni.tex» (caricato da entrambe le
% destinazioni) ne usa alcuni attivamente.
% =====================================================================
